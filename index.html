    翻译设置
    
        
      
    
      
    
        
    
          
    生成英文版需要接一个翻译服务
    
          
    用你自己的 API Key，翻译质量最好；Key 只存在这台设备上，不经过我们的服务器。
    
          
    没有 Key？到服务商开放平台注册一个即可 —— DeepSeek 按量计费，一份简历通常几分钱。
    
        
    
        
        
        
        
        
    Key 只保存在这台设备的浏览器里，不会上传到任何服务器。建议使用自己的 Key 并设置额度上限。
    

        
        
    
          不知道怎么获取 API Key？照着做（以 DeepSeek 为例）
          
      
            
    1. 
              打开
              platform.deepseek.com，用手机号注册并登录（新账号一般有赠送额度）
            
      2. 
            
    2. 在左侧菜单找到「API keys」，点「创建 API key」（有的版本叫「创建新密钥」）
      3. 
            
    3. 
              复制以 sk- 开头的那一串——它只显示这一次，先粘到记事本里
            
      4. 
            
    4. 回到这里，把它粘进上面的「API Key」输入框，点「测试连接」确认能通
      5. 
            
    5. 如果提示余额不足：在左侧「充值」里充一点，一份简历通常只花几分钱
      6. 
          
    
          
    
            Key 相当于账号密码，不要发给别人；万一泄漏，回到同一页面删除重建一个就好。
            其他服务商（Kimi、通义、智谱、OpenAI）流程类似，把「服务商」换成对应平台即可。
